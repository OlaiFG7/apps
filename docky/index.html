ARQUITECTURA MODULAR

Pequeño por fuera.
Ordenado por dentro.

Workspaces independientes, actividades en vivo y convivencia configurable con el Dock nativo de macOS y con Notchy.

▤

Workspaces independientes

Crea, renombra, elimina y alterna espacios de trabajo (el último no se puede eliminar). Cada uno guarda sus apps, carpetas, separadores y widgets. Configura tamaño de iconos, ampliación, etiquetas, solapamiento y ocultación automática.

ESPACIOS
⌘

Atajos y trackpad

Cambia de espacio al instante con Control–Opción–1 a Control–Opción–9, desde el selector de workspace o mediante un gesto de trackpad habilitado. Los gestos nativos de macOS permanecen separados.

NAVEGACIÓN
◉

Marcador «Apps abiertas»

Muestra las aplicaciones en ejecución que no están fijadas. Un marcador móvil define su posición en cada workspace (si falta, aparecen al final) y su menú contextual permite activarlas o fijarlas.

VENTANAS
✦

Actividades en vivo

Presentaciones compactas y expandidas sobre el Dock para multimedia, letras, Pomodoro, cambios de workspace, estado de agentes, calendario, tiempo, batería y HUDs de volumen y brillo.

SUPERFICIES
⇄

Coordinación con Notchy

Protocolo local opcional mediante notificaciones distribuidas y concesión renovable (lease) para enrutar los HUDs de volumen y brillo por pantalla. Al expirar la concesión, Notchy retoma su propio HUD.

NOTCHY
⚙

Dock nativo de macOS

Puede ajustar la ocultación automática del Dock nativo con retardo de 10 s, guardar copia de seguridad y reiniciar el proceso Dock. Incluye la acción Restore macOS Dock.

SISTEMA

Almacenamiento local: los workspaces se guardan en ~/Library/Application Support/MagicDock/workspaces.json; el resto de preferencias usan el sistema estándar defaults de macOS. La coordinación con Notchy es un protocolo local experimental; conviene validar pantalla completa y configuraciones multimonitor.

Servicios y panel no activante

El widget de tiempo envía únicamente la ciudad configurada al servicio de geocodificación de Open-Meteo y usa esas coordenadas para la previsión, sin clave API ni sensor GPS.

Algunos widgets con entrada de texto (como Nota rápida o conversores) están limitados por el panel no activante de macOS y ofrecen acciones explícitas de pegado.

Límites de widgets conectados

La cuadrícula de contribuciones de GitHub usa actualmente datos de ejemplo, no un feed en directo. El monitor de agentes IA solo refleja eventos explícitos enviados por integraciones compatibles.

Los controles de Apple Home invocan Atajos de macOS configurados por el usuario y pueden abrir Casa o Atajos; no descubren accesorios HomeKit directamente.

TÚ DECIDES

Permisos y privacidad,
sin sorpresas.

La compilación actual no está aislada en sandbox. Cada función solicita permisos solo cuando decides usarla.

Datos y servicios

Calendario (EventKit): solicita acceso completo solo tras una acción del usuario y lee eventos localmente en memoria sin escribir cambios.

Tiempo (Open-Meteo): envía solo la ciudad configurada para obtener coordenadas y previsión. Los accesos directos de ocio abren sitios externos en tu navegador.

Permisos del sistema

Controlar Música, Spotify, YouTube Music o Safari puede requerir permiso de Automatización (y permitir JavaScript desde Apple Events en Safari). Las funciones de ventanas, gestos o HUD usan Accesibilidad cuando se activan.

La integración con agentes mediante hooks locales es opcional y sus limitaciones están documentadas en docs/agent-activity.md.

EMPEZAR

El Dock es solo
el principio.

No se distribuyen binarios precompilados desde esta página. Docky se compila localmente con Xcode para macOS 14 o posterior.

01

Prueba y compila

Ejecuta DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer swift test -j 4 y luego ./build-app.sh --run (o --install para instalar en /Applications).

02

Organiza tus workspaces

Crea espacios para cada contexto, añade apps, carpetas y widgets, y sitúa el marcador «Apps abiertas» donde prefieras.

03

Ajusta tema y permisos

Elige uno de los 14 temas, configura iconos tematizados o nativos y activa los permisos solo para las integraciones que necesites.

En el equipo de desarrollo de referencia, las Command Line Tools independientes carecían de macros de SwiftUI, por lo que fue necesario seleccionar Xcode con DEVELOPER_DIR. El script firma con identidad local de desarrollo o ad hoc; una identidad estable ayuda a conservar permisos entre compilaciones.

PREGUNTAS FRECUENTES

En pocas palabras.

¿Hay un binario listo para descargar aquí?

No. Docky está en desarrollo activo y se compila localmente desde el código fuente con Xcode mediante ./build-app.sh --run o --install.

¿Cómo funciona la coordinación con Notchy?

Ambas apps pueden activar la coordinación local por notificaciones distribuidas y una concesión renovable para enrutar los HUDs de volumen y brillo por pantalla. Si la concesión expira, Notchy retoma su propio HUD.

¿Por qué GitHub muestra datos de ejemplo?

La vista de contribuciones de GitHub usa actualmente datos de ejemplo en lugar de una conexión en directo con la API de GitHub.

¿Puedo restaurar el Dock nativo de macOS?

Sí. Docky incluye la acción Restore macOS Dock para restaurar la copia de seguridad y reiniciar el proceso Dock, aunque no garantiza recuperación automática tras cualquier fallo inesperado.
